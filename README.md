## 2. ติดตั้งที่ทำงานครั้งแรก

### สิ่งที่ต้องเตรียม
- [ ] เครื่องแม่ข่าย Windows ที่ **เปิด BitLocker** แล้ว (ดูข้อ 9.2)
- [ ] ฮาร์ดดิสก์ภายนอก 2 ลูก: ลูกที่ 1 เสียบไว้ตลอด / ลูกที่ 2 ถอดเก็บ (เปิด BitLocker ทั้งคู่)
- [ ] ชุดโปรแกรม — เลือกแบบใดแบบหนึ่ง
  - **มีอินเทอร์เน็ต:** ติดตั้ง Git แล้ว `git clone` จาก GitHub (Private) ไปที่ `C:\RehabApp`
  - **ไม่มีอินเทอร์เน็ต:** ไฟล์ `rehab-offline-YYYYMMDD.zip` จาก USB (สร้างที่บ้านด้วย `make-offline-bundle.ps1`) แตกไฟล์ไปที่ `C:\RehabApp`
- [ ] ไฟล์ฟอนต์ TH Sarabun New วางใน `C:\RehabApp\assets\fonts\` (ดูข้อ 10)

### ขั้นตอน
1. คลิกขวาที่ปุ่ม Start → **Windows PowerShell (Admin)** หรือ **Terminal (Admin)**
2. พิมพ์ทีละบรรทัด (กด Enter หลังแต่ละบรรทัด)
   ```
   cd C:\RehabApp
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```
3. ตอบคำถามทีละข้อ (กด Enter = ใช้ค่าในวงเล็บ):
   - โฟลเดอร์เก็บข้อมูล → Enter (ใช้ `C:\RehabData`)
   - พอร์ต → Enter (ใช้ 443)
   - **รหัสหน่วยงาน** (อย่างน้อย 8 ตัว) — รหัสกลางที่ทุกเครื่องใส่ครั้งแรก
   - ชื่อ-นามสกุล และ **รหัสผ่านของหัวหน้า** (ผู้ดูแลระบบคนแรก — **อย่างน้อย 12 ตัว**; ผู้ดูแลไม่ใช้ OTP จึงต้องใช้รหัสยาวกว่าผู้ใช้ทั่วไป)
4. เมื่อเสร็จ โปรแกรม Notepad จะเปิดไฟล์ **"พิมพ์ใส่ซองแล้วลบไฟล์นี้.txt"** → พิมพ์ออกมา → ใส่ซองปิดผนึก → **ลบไฟล์นั้นทิ้ง** (ดูข้อ 8)
5. เปิดเบราว์เซอร์ที่เครื่องแม่ข่าย ไปที่ `https://localhost` → ใส่รหัสหน่วยงาน → กดชื่อหัวหน้า → ใส่รหัสผ่าน
6. ไปที่ **ตั้งค่า → สำรอง/กู้คืนข้อมูล** ใส่ตำแหน่งฮาร์ดดิสก์ภายนอก (เช่น `E:\RehabBackup`) และฮาร์ดดิสก์ถอดเก็บ (เช่น `F:\RehabBackup`) แล้วกด **สำรองข้อมูลทันที** เพื่อทดสอบ
7. ไปที่ **ตั้งค่า → ตั้งค่าระบบ** ตรวจชื่อหน่วยงาน และ **เพิ่มวันหยุดทางพุทธศาสนา/วันหยุดชดเชย** ของปีนี้
8. ไปที่ **ตั้งค่า → ผู้ใช้และสิทธิ์** เพิ่มบัญชีรองหัวหน้าและเจ้าหน้าที่ (ตั้งรหัสชั่วคราว ระบบบังคับเปลี่ยนเมื่อเข้าครั้งแรก) จากนั้นขอ **ให้สิทธิ์ผู้ดูแล** กับรองหัวหน้า → รองหัวหน้าเข้าระบบแล้วกดยืนยันในหน้า **ยืนยัน 2 คน** (ครั้งถัดไปที่รองหัวหน้าเข้าระบบ ถ้ารหัสสั้นกว่า 12 ตัว ระบบจะให้ตั้งรหัสใหม่) · ตรวจ **เวลาราชการ** ใน ตั้งค่า → ตั้งค่าระบบ → "ความปลอดภัยผู้ดูแลระบบ" (ใช้แจ้งเตือนเมื่อผู้ดูแลเข้าระบบนอกเวลา)
9. ติดตั้งใบรับรองที่เครื่องลูกข่ายทุกเครื่อง (ข้อ 3)

> 📷 ภาพประกอบทีละขั้นจะเพิ่มในโฟลเดอร์ `docs/images/` หลังทดลองติดตั้งจริงครั้งแรก

### สภาพแวดล้อมทดสอบ (ลองอัปเดตก่อนใช้จริง)
ติดตั้งอีกชุดที่ `C:\RehabApp-Test` แล้วรัน `install.ps1 -Staging` → ได้บริการ `RehabSystemTest` พอร์ต 8443 ข้อมูลแยกที่ `C:\RehabData-Test`
ใช้ `https://ชื่อเครื่อง:8443` — หน้าจอจะมีแถบเหลือง "สภาพแวดล้อมทดสอบ"

## 3. ติดตั้งใบรับรองที่เครื่องลูกข่าย
ระบบใช้ HTTPS ด้วยใบรับรองของหน่วยงานเอง เครื่องลูกข่ายต้องเชื่อใบรับรองนี้ **ครั้งเดียว**:
1. คัดลอกไฟล์ `ติดตั้งใบรับรองนี้ที่เครื่องลูกข่าย-rehab-ca.cer` (อยู่ใน `C:\RehabApp`) ใส่ USB
2. ที่เครื่องลูกข่าย ดับเบิลคลิกไฟล์ → **Install Certificate** → เลือก **Local Machine** → **Place all certificates in the following store** → **Browse** → **Trusted Root Certification Authorities** → OK → Finish
3. เปิด Chrome/Edge ไปที่ `https://ชื่อเครื่องแม่ข่าย` (ดูชื่อเครื่องได้จากหน้าจอตอนติดตั้งเสร็จ)

## 4. อัปเดตโปรแกรม
**ลองที่สภาพแวดล้อมทดสอบก่อนเสมอ** แล้วค่อยอัปเดตตัวจริง

```
cd C:\RehabApp
powershell -ExecutionPolicy Bypass -File .\update.ps1                    (ดึงจาก GitHub)
powershell -ExecutionPolicy Bypass -File .\update.ps1 -Zip E:\rehab.zip  (จาก USB)
```
สคริปต์จะ: **สำรองข้อมูลก่อน** → ดึงโค้ดใหม่ → build → เริ่มบริการ (ปรับโครงสร้างฐานข้อมูลอัตโนมัติ) → ตรวจว่าระบบตอบ
ถ้าพัง ระบบจะ **ย้อนกลับเวอร์ชันเดิมและข้อมูลก่อนอัปเดตให้อัตโนมัติ**

## 5. สำรองข้อมูล
หลัก 3-2-1: ชุดที่ 1 ในเครื่อง (`C:\RehabData\backups`) / ชุดที่ 2 ฮาร์ดดิสก์ภายนอกที่เสียบไว้ / ชุดที่ 3 ฮาร์ดดิสก์ถอดเก็บ

| อะไร | เมื่อไร |
|---|---|
| สำรองอัตโนมัติ | 08.00 12.00 16.00 (วันทำการ) + 22.00 ทุกคืน — ถ้าเครื่องปิดตอนถึงเวลา จะทำทันทีเมื่อเปิดเครื่อง |
| เก็บไว้ | รายวัน 30 วัน / รายสัปดาห์ 12 / รายเดือน 12 / รายปีเก็บตลอด |
| ทดสอบกู้คืนอัตโนมัติ | ทุกวันอาทิตย์ 23.00 (กู้ลงฐานทดสอบ นับจำนวนข้อมูลเทียบ) |
| ดิสก์ถอดเก็บ | **อย่างน้อยเดือนละครั้ง**: เสียบดิสก์ลูกที่ 2 → ตั้งค่า → สำรอง/กู้คืน → **สำรองลงฮาร์ดดิสก์ถอดเก็บ** → ถอดไปเก็บนอกห้องเครื่อง (ระบบเตือนถ้าเกิน 30 วัน) |

**แถบแดง** ในหน้าแรกของผู้ดูแล = มีปัญหา (สำรองล้มเหลว / ดิสก์ภายนอกหลุด / พื้นที่เกิน 80%) — เสียบดิสก์กลับ ระบบทำงานต่อเอง
ไฟล์สำรอง (`.rhbk`) เข้ารหัสแล้ว เปิดได้เฉพาะเมื่อมี **BACKUP_KEY** (อยู่ในซองปิดผนึก)

## 6. กู้คืนข้อมูล
**ต้องใช้ผู้ดูแล 2 คน** (หัวหน้า + รอง)
1. ผู้ดูแลคนที่ 1: ตั้งค่า → สำรอง/กู้คืน → เลือกไฟล์ตามวันเวลา → ใส่เหตุผล → **ส่งคำขอกู้คืน**
2. ผู้ดูแลคนที่ 2: ตั้งค่า → **ยืนยัน 2 คน** → กด **ยืนยันและทำรายการ**
3. ระบบ **สำรองข้อมูลปัจจุบันก่อนเสมอ** แล้วจึงกู้คืน — ทุกคนต้องโหลดหน้าใหม่/เข้าระบบใหม่

**กรณีอีกคนไม่อยู่นาน:** ผู้ขอกด "ใช้รหัสฉุกเฉิน" แล้วใส่รหัสจากซองปิดผนึก → ระบบบันทึกประวัติ และ **รหัสนั้นใช้ไม่ได้อีก** ต้องสร้างรหัสใหม่ในหน้า "ยืนยัน 2 คน" แล้วพิมพ์ใส่ซองใหม่ทันที

**กู้คืนจากไฟล์ในดิสก์ภายนอก** (เมื่อเครื่องเสีย): คัดลอกไฟล์ `.rhbk` และ `.rhbk.sha256` ไปไว้ที่ `C:\RehabData\backups` ของเครื่องใหม่ แล้วทำตามข้อ 7

## 7. ย้ายเครื่องแม่ข่าย / เปลี่ยนฮาร์ดดิสก์
1. เครื่องเดิม: ตั้งค่า → สำรอง/กู้คืน → **สำรองข้อมูลทันที** (หรือใช้ไฟล์ล่าสุดในดิสก์ภายนอก)
2. เครื่องใหม่: ติดตั้งตามข้อ 2 แต่ **ก่อนรัน install.ps1** ให้สร้างไฟล์ `C:\RehabApp\.env` โดยคัดลอกจากเครื่องเดิม (ต้องมี BACKUP_KEY เดิม — ถ้าไม่มีใช้ค่าจากซองปิดผนึก)
3. คัดลอกไฟล์ `.rhbk` ล่าสุด (และ `.sha256`) ไปที่ `C:\RehabData\backups`
4. หยุดบริการแล้วกู้คืน:
   ```
   Stop-Service RehabSystem
   cd C:\RehabApp
   npx tsx scripts/restore-cli.mts ชื่อไฟล์.rhbk
   Start-Service RehabSystem
   ```
5. เครื่องลูกข่ายต้องติดตั้งใบรับรองใหม่ (ข้อ 3) เพราะเครื่องใหม่สร้างใบรับรองใหม่
6. **เปลี่ยนฮาร์ดดิสก์ภายนอก:** เสียบลูกใหม่ → เปิด BitLocker → แก้ตำแหน่งในหน้า สำรอง/กู้คืน → กด สำรองทันที

## 8. รหัสสำคัญและซองปิดผนึก
หลังติดตั้ง ให้พิมพ์และเก็บในซองปิดผนึก (ตู้เซฟ/ที่ปลอดภัย) โดยหัวหน้า:
- **BACKUP_KEY** — กุญแจเปิดไฟล์สำรอง *ถ้าหาย ไฟล์สำรองทั้งหมดใช้ไม่ได้*
- **รหัสฉุกเฉิน** — ยืนยันแทนผู้ดูแลอีกคน (ใช้แล้วสร้างใหม่ทันที)
- รหัสกู้คืน BitLocker ของเครื่องแม่ข่ายและฮาร์ดดิสก์สำรองทั้ง 2 ลูก

ไฟล์ `.env` (มี BACKUP_KEY) อยู่ที่ `C:\RehabApp\.env` อ่านได้เฉพาะผู้ดูแลเครื่อง — **ห้ามนำเข้า Git ห้ามส่งทางแชท/อีเมล**

## 9. ความปลอดภัย (เช็คลิสต์)

### 9.1 กายภาพและการปฏิบัติ
- [ ] เครื่องแม่ข่ายอยู่ในห้องล็อก ต่อ UPS และตั้งให้ปิดเครื่องอย่างปลอดภัยเมื่อไฟดับนาน
- [ ] อัปเดต Windows และแอนตี้ไวรัสสม่ำเสมอ / ปิด Autorun ของ USB
- [ ] ห้ามบอกรหัสผ่านต่อกัน ห้ามจดติดจอ ล็อกหน้าจอทุกครั้งที่ลุก
- [ ] บัญชีของผู้ที่ย้าย/ลาออก → **ระงับบัญชี** ทันที (ไม่ลบ เพื่อเก็บประวัติ) และเปลี่ยนรหัสหน่วยงาน

### 9.2 เปิด BitLocker (ทั้งเครื่องแม่ข่ายและฮาร์ดดิสก์สำรอง)
1. Control Panel → **BitLocker Drive Encryption** → **Turn on BitLocker** ที่ไดรฟ์ C:
2. เลือกเก็บ **Recovery key** → Print → ใส่ซองปิดผนึก
3. ฮาร์ดดิสก์ภายนอก: เลือกไดรฟ์ → Turn on BitLocker → ตั้งรหัสผ่าน → เลือก "Automatically unlock on this computer" สำหรับดิสก์ที่เสียบไว้ตลอด
   (Windows Home ไม่มี BitLocker — ต้องใช้ Windows Pro ขึ้นไป)

### 9.3 เครือข่าย (ให้ฝ่าย IT ตั้ง)
- เข้าระบบได้เฉพาะใน LAN — **ห้ามเปิดพอร์ตจากอินเทอร์เน็ต ห้าม Remote access** (install.ps1 ตั้ง Firewall ให้รับเฉพาะโปรไฟล์ Domain/Private)
- ขาออกอนุญาตเฉพาะ `api.line.me` (พอร์ต 443) สำหรับแจ้งเตือน LINE (ขั้นที่ 3)
- ข้อความ LINE **ไม่มีข้อมูลผู้ต้องขังทุกกรณี**

### 9.4 PDPA
- ทุกคนที่ลงทะเบียนต้องมีหลักฐานลงนามยินยอม (ติ๊กในขั้นยืนยัน + เก็บต้นฉบับในแฟ้ม) — พิมพ์แบบฟอร์มเปล่าได้จากหน้าลงทะเบียน
- ข้อความแบบฟอร์มยินยอมเป็น **ร่าง** — ให้ฝ่ายกฎหมาย/ผู้รับผิดชอบ PDPA ของหน่วยงานตรวจก่อนใช้จริง
- ระยะเวลาเก็บข้อมูลและการทำลายเมื่อพ้นระยะ: จะตั้งค่าได้ในขั้นถัดไป (ต้องยืนยันระยะเวลากับหน่วยงาน)

### 9.5 เมื่อสงสัยว่าข้อมูลรั่ว
1. **ระงับบัญชี** ที่สงสัยทันที (ตั้งค่า → ผู้ใช้) และเปลี่ยนรหัสหน่วยงาน
2. ตั้งค่า → **ประวัติการใช้งาน** ค้นตามผู้ใช้/ช่วงเวลา ดูการเปิดดูข้อมูลอ่อนไหว การส่งออก การพิมพ์ — **อย่าแก้ไขหรือปิดเครื่อง** เพื่อเก็บหลักฐาน
3. รายงานผู้บังคับบัญชาและผู้รับผิดชอบ PDPA ของหน่วยงาน (กฎหมายกำหนดแจ้ง สคส. ภายใน 72 ชั่วโมงเมื่อมีความเสี่ยงต่อสิทธิของเจ้าของข้อมูล)
4. บันทึกเหตุการณ์ วันเวลา สิ่งที่พบ และสิ่งที่ทำไปแล้ว

| อาการ | ทำอย่างไร |
|---|---|
| เปิดเว็บไม่ได้ | ที่เครื่องแม่ข่าย: เปิด **Services** (พิมพ์ services.msc) → หา `RehabSystem` → Start / หรือ PowerShell (Admin): `Restart-Service RehabSystem` |

| ดูข้อความผิดพลาดของระบบ | `C:\RehabApp\scripts\daemon\` (ไฟล์ log ของ Windows Service) |

## 13. สำหรับผู้พัฒนา (เครื่องที่บ้าน)
```
npm install
npm run seed          # สร้างข้อมูลปลอม ~500 คน
npm run dev           # http://localhost:3000
npm run dev:otp -- วิภาวรรณ   # (เฉพาะเมื่อเปิด OTP ในตั้งค่า) ดูรหัส OTP ในข้อมูลปลอม
npm test              # unit test กฎสำคัญ
npm run typecheck
npm run security-check   # ตรวจความปลอดภัยอัตโนมัติ (ต้องเปิด dev server ก่อน)
```
- **รหัสทดสอบทุกบทบาท (ข้อมูลปลอม):** ดูที่ [`docs/TEST-ACCOUNTS.md`](docs/TEST-ACCOUNTS.md) — รหัสหน่วยงาน ชื่อผู้ใช้ รหัสผ่าน (ผู้ดูแลใช้รหัสแยก ≥ 12 ตัว) และวิธีแก้เมื่อเข้าระบบไม่ได้
- ไฟล์ `.env.local` (เครื่องพัฒนา): `APP_ENV=development`, `DATA_DIR=./data`, `BACKUP_KEY=...`
- เปลี่ยนโครงสร้างฐานข้อมูล: แก้ `src/lib/db/schema.ts` → `npm run db:generate` → commit ไฟล์ใน `drizzle/` (ห้ามแก้ฐานข้อมูลด้วยมือ)
- เทคโนโลยี: Next.js (App Router) + TypeScript + Tailwind CSS + SQLite (better-sqlite3 + Drizzle ORM, WAL mode)
- สเปกทั้งหมด: `docs/spec.md` · โครงสร้างข้อมูล: `docs/data-model.md`
- รูปภาพตกแต่ง: ตอนนี้ใช้ภาพวาด SVG ของระบบเอง (ไม่มีลิขสิทธิ์ผู้อื่น) — ถ้าเพิ่มภาพจาก Unsplash/Pexels ให้ระบุแหล่งที่มาที่นี่
