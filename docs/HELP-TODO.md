# เนื้อหาที่ต้องใส่ในคู่มือ (รวบรวมจากคำอธิบายที่ย้ายออกจากหน้าจอ — สเปก 4.3A)

เมื่อ 10 ต.ค. 2569 ปรับข้อความบนหน้าจอให้สั้นตามสเปก 4.3A คำอธิบายยาวย้ายไปอยู่ในปุ่ม (?) ของแต่ละหน้า
ไฟล์นี้คือรายการหัวข้อที่คู่มือแยกบทบาท (สเปก 4.3 "คู่มือแยกบทบาทพิมพ์ได้") ต้องครอบคลุม
ติ๊ก `[x]` เมื่อเขียนลงคู่มือแล้ว · ภาพหน้าจอประกอบอยู่ที่ `docs/screenshots/`

สัญลักษณ์: **(?)** = มีในปุ่ม (?) ของหน้านั้นแล้ว · **ไม่มีบนจอ** = ตั้งใจไม่แสดงบนหน้าจอ ต้องอยู่ในคู่มือเท่านั้น

## ทุกบทบาท

### เข้าสู่ระบบ / ล็อกหน้าจอ
- [ ] **ไม่มีบนจอ** รหัสหน่วยงานได้จากใคร (หัวหน้า/รองหัวหน้า) · ตัวพิมพ์เล็ก-ใหญ่ต้องตรงกัน
- [ ] **ไม่มีบนจอ** "จดจำเครื่องนี้ 30 วัน": ไม่ติ๊ก = ใช้ได้จนปิดเบราว์เซอร์ ไม่เกิน 12 ชั่วโมง (ใช้กับเครื่องที่ใช้ร่วมกัน)
- [ ] **ไม่มีบนจอ** ลืมรหัสผ่าน / บัญชีถูกระงับชั่วคราว (ผิด 5 ครั้ง ล็อก 15 นาที): ให้หัวหน้า/รองรีเซ็ต
- [ ] **ไม่มีบนจอ** เข้าครั้งแรกหรือหลังรีเซ็ต ต้องตั้งรหัสผ่านใหม่ · ผู้ดูแลระบบต้องยาวอย่างน้อย 12 ตัว
- [ ] **ไม่มีบนจอ** OTP: โทรศัพท์หาย/เปลี่ยนเครื่อง → ผู้ดูแลอีกคนขอ "รีเซ็ต OTP" ในหน้าผู้ใช้ (ยืนยัน 2 คน) หรือใช้รหัสฉุกเฉิน
- [ ] **ไม่มีบนจอ** ล็อกหน้าจอ: งานที่พิมพ์ค้างไว้เก็บเป็นร่างให้เจ้าของเดิม · ปุ่ม "เปลี่ยนผู้ใช้"
- [ ] **ไม่มีบนจอ** หน้า "ไม่มีสิทธิ์": หัวหน้า/รองปรับสิทธิ์ได้ที่หน้าผู้ใช้และสิทธิ์

### หน้าแรก "งานของฉันวันนี้"
- [ ] **(?)** บันทึกเช็คชื่อ + ผลกิจกรรม แล้วกด "บันทึกและปิดคาบ" — ใช้คำนวณค่าตอบแทน
- [ ] **(?)** วิทยากรภายนอกยังไม่ยืนยัน (อีกไม่เกิน 14 วันถึงวันสอน): ส่งหนังสือ/โทรยืนยัน แล้วเปลี่ยนสถานะที่ตารางของรุ่น

### ค้นหาบุคคล / หน้าบุคคล
- [ ] **(?)** พิมพ์ 2–3 ตัวอักษรขึ้นไป · กด `/` จากหน้าใดก็ได้เพื่อเปิดค้นหา
- [ ] **(?)** เลขประจำตัวไม่เปลี่ยนแม้ย้ายเรือนจำ แก้เฉพาะกรณีบันทึกผิด (ผู้ดูแล + เหตุผล)
- [ ] **ไม่มีบนจอ** เลขบัตรซ้ำกับบุคคลอื่น: แจ้งหัวหน้า/รองเพื่อรวมประวัติ

## เจ้าหน้าที่ฟื้นฟู (กลุ่ม A)

### ลงทะเบียนเข้ารุ่น
- [ ] **(?)** ช่องบังคับ: เลขประจำตัว ชื่อ นามสกุล — ที่เหลือกรอกภายหลังได้ · บันทึกร่างอัตโนมัติทุก 30 วินาที
- [ ] **(?)** เลขประจำตัวแก้ไม่ได้หลังบันทึก (ยกเว้นผู้ดูแลพร้อมเหตุผล)
- [ ] **(?)** เลขบัตรใช้ค้นประวัติเดิม · ไม่มีเลขบัตรก็ไปต่อได้ ระบบเทียบชื่อ-สกุลและวันเกิด
- [ ] **(?)** ไม่ยินยอม: ระบบแจ้งหัวหน้า/รองพิจารณา
- [ ] **ไม่มีบนจอ** ลงซ้ำหลักสูตรเดิม (บล็อก): ต้องให้หัวหน้า/รองลงทะเบียนพร้อมเหตุผล
- [ ] **ไม่มีบนจอ** มีลักษณะต้องห้าม: บันทึกเป็นร่างและปรึกษาหัวหน้า/สถานพยาบาลก่อนยืนยันรับเข้า
- [ ] **ไม่มีบนจอ** เลขที่บันทึกว่าออกจากเรือนจำแล้ว: กลับเข้ามาใหม่จะได้เลขประจำตัวใหม่

### นำเข้าจาก Excel
- [ ] **(?)** ใช้ลงทะเบียนจำนวนมาก หรือนำเข้ารุ่นเก่าย้อนหลัง · ตรวจกฎกันซ้ำทุกแถว
- [ ] **(?)** แถวไม่ผ่าน: ดาวน์โหลดไปแก้แล้วนำเข้าใหม่ หรือลงทะเบียนทีละคน
- [ ] **(?)** แถว "กำลังอบรม" ที่ยังไม่ลงนามยินยอม นำเข้าเป็น "ร่าง"
- [ ] **ไม่มีบนจอ** นำเข้าแล้วดูได้ที่หน้ารายชื่อของรุ่น

### สร้างรุ่น / ตารางกิจกรรม
- [ ] **(?)** วันสิ้นสุดคำนวณโดยข้ามวันหยุด · สร้างตารางจากแม่แบบหรือคัดลอกจากรุ่นก่อน
- [ ] **(?)** คัดลอก: วันที่ n ของรุ่นเดิม → วันอบรมที่ n ของรุ่นใหม่ · ไม่คัดลอกคาบยกเลิก/คาบชดเชย
- [ ] **(?)** ลากการ์ดคาบ (จับที่ไอคอน ⋮⋮) เพื่อย้ายวัน · บนแท็บเล็ตใช้แท็บ "รายละเอียดคาบ" เปลี่ยนวันที่แทนการลาก
- [ ] **(?)** คาบที่เช็คชื่อแล้ว: แก้เวลา/สถานที่ได้ แต่ย้ายวันไม่ได้
- [ ] **(?)** เปลี่ยนวิทยากรเป็นช่วง: ข้ามคาบล็อก/ยกเลิก/รุ่นปิด · คนใหม่อยู่ในคาบแล้วจะเอาคนเดิมออกอย่างเดียว · สอนซ้อนจะแจ้ง
- [ ] **ไม่มีบนจอ** คัดลอกข้อความแจ้งวิทยากรภายนอก แล้ววางในแชต/อีเมล
- [ ] **ไม่มีบนจอ** จำนวนวิทยากรเกินสูงสุดของหัวข้อ: เอาคนเดิมออกก่อน หรือให้หัวหน้า/รองปรับที่คลังหัวข้อ

### เช็คชื่อ / กรอกเร็ว / คาบของฉัน
- [ ] **(?)** กรอกเร็ว: Enter/ลูกศรลง = คนถัดไป · ซ้าย-ขวา = คาบถัดไป · คัดลอกจาก Excel วางได้ทั้งแผ่น · ไม่ใช้ Ctrl+S ให้กดปุ่มบันทึก
- [ ] **(?)** เช็คชื่อและบันทึกผลได้ตั้งแต่เวลาเริ่มคาบ
- [ ] **(?)** ผู้ที่ไม่อยู่ในรายชื่อผู้สอนบันทึกได้เป็น "บันทึกแทนผู้สอน" (เก็บผู้สอนกับผู้บันทึกแยกกัน)
- [ ] **(?)** เปลี่ยนตัวผู้สอนที่ตารางของรุ่น · ค่าตอบแทนคิดจากการสอนจริง
- [ ] **(?)** คาบชดเชย: ผู้เข้าร่วม = เฉพาะผู้ที่ติดเหตุราชทัณฑ์ · ค่าตอบแทนตามตั้งค่า
- [ ] **(?)** คาบที่ยกเลิกไม่ต้องเช็คชื่อ (เหตุผลอยู่ในประวัติการแก้ไข)
- [ ] **ไม่มีบนจอ** คาบถูกล็อกหลังอนุมัติค่าตอบแทน: แก้ได้เฉพาะหัวหน้า/รองปลดล็อกพร้อมเหตุผล
- [ ] **ไม่มีบนจอ** ชิป "มีเหตุการณ์ต้องแจ้งเวร": บันทึกแล้วระบบเปิดกล่องจดหมายเวรพร้อมเติมรุ่น/คาบให้

### แฟ้มการอบรมรายคน / แบบประเมิน
- [ ] **(?)** แบบประเมินผูกกับการลงทะเบียนครั้งนี้ คะแนนจากการต้องโทษรอบก่อนไม่ถูกนำมาใช้
- [ ] **(?)** ครบหลักสูตร → สร้างงานจำหน่ายและติดตามเดือนที่ 1 3 6 12 นับจากวันจำหน่าย

### บสต. / รท.101 / ออกจากเรือนจำ
- [ ] **(?)** บสต.: กด "ลง บสต. แล้ว" หลังลงในระบบ บสต. · ผลติดตามบันทึกในแฟ้มของแต่ละคน
- [ ] **(?)** รท.101: คนละ 1 ครั้งต่อหลักสูตรเมื่อครบหลักสูตร · ติ๊กหลายคนแล้วกดครั้งเดียว
- [ ] **(?)** ออกจากเรือนจำ: บันทึกเมื่อทราบว่าออกแล้วเท่านั้น · ยกเลิกภายหลังได้ ระบบคืนสถานะเดิม

### กล่องจดหมายเวร
- [ ] **(?)** ผู้รับต้องกด "รับทราบภารกิจ" ทีละข้อ · ระบบบันทึกผู้รับทราบและเวลา
- [ ] **(?)** เรื่องสุขภาพ: ผู้ไม่มีสิทธิ์เห็นเพียง "มีเรื่องสุขภาพ — ติดต่อพยาบาล"
- [ ] **ไม่มีบนจอ** ผู้ช่วย (กลุ่ม B) เห็นเฉพาะข้อความถึงตนหรือทีมของรุ่นที่สอน แต่ส่งถึงเจ้าหน้าที่หลักได้

### หลักสูตร 3 วัน / เอกสารราชการ
- [ ] **(?)** รายชื่อแนะนำ: ผ่าน 12 วัน/ชุมชนบำบัดแล้ว ยังไม่เคยเข้า 3 วัน ยังไม่ออก · วันพ้นโทษโดยประมาณไม่รวมพักโทษ/ลดวันต้องโทษ
- [ ] **(?)** เอกสารสร้างจากแม่แบบ เติมข้อมูลของรุ่นให้ แก้ได้ก่อนพิมพ์ · ล็อกแล้วต้องปลดล็อกก่อนแก้
- [ ] **(?)** ช่อง "…………": เติมในเนื้อความ หรือเติมข้อมูลของรุ่นแล้วสร้างเอกสารใหม่
- [ ] **ไม่มีบนจอ** บันทึกส่งต่อข้อมูลสุขภาพได้หลังยืนยันรับเข้ารุ่น · ไม่เชื่อมกับระบบ HIV

## การเงิน

- [ ] **(?)** ค่าตอบแทนคิดจากการสอนจริงของคาบที่ปิดแล้ว · รอบเบิกต่อรุ่น (ทั้งรุ่นหรือช่วงวันที่ เช่น รายเดือน)
- [ ] **(?)** อนุมัติแล้วยอดคงที่ ล็อกเช็คชื่อ/ผลกิจกรรม · คาบที่เบิกแล้วไม่ถูกเบิกซ้ำ
- [ ] **(?)** ข้อมูลเปลี่ยนหลังอนุมัติ: ปลดล็อก → อนุมัติใหม่ → พิมพ์และลงนามใหม่
- [ ] **(?)** ภาระงานชั่วโมงสอนรวมคาบที่เบิกไม่ได้ ใช้ประกอบการประเมินผลงาน
- [ ] **(?)** งบของรุ่น: ค่าวิทยากรไม่ต้องบันทึก ตัดจากรอบเบิกที่อนุมัติ · รุ่นปิดแล้วยังบันทึกจ่ายจริง/คืนเงินได้
- [ ] **(?)** ทะเบียนวิทยากร: วิทยากรภายในใช้ชื่อจากบัญชี เติมเลขบัตร ที่อยู่ บัญชี · วิธีค้นตำบล
- [ ] **ไม่มีบนจอ** อนุมัติรอบที่มียอดของตนเองไม่ได้ ต้องให้หัวหน้า/รองอีกคนอนุมัติ
- [ ] **ไม่มีบนจอ** ใช้เกินงบ (แดง): ต้องให้หัวหน้า/รองยืนยันที่หน้างบของรุ่น
- [ ] **ไม่มีบนจอ** เอกสารการเงินพิมพ์เยื้อง: หัวหน้า/รองปรับที่ ตั้งค่า → ปรับตำแหน่งการพิมพ์

## ผู้ดูแลระบบ (หัวหน้า/รอง)

- [ ] **(?)** ยืนยัน 2 คน: กู้คืน ลบถาวร เปลี่ยนสิทธิ์ผู้ดูแล · ผู้ขอกับผู้ยืนยันต้องคนละคน · มอบอำนาจไม่ได้
- [ ] **(?)** รหัสฉุกเฉิน: ใช้แทนผู้ดูแลอีกคนเมื่อไม่อยู่นาน ใช้ครั้งเดียว พิมพ์ใส่ซองปิดผนึก
- [ ] **(?)** สำรองข้อมูล: อัตโนมัติทุก 4 ชม. (08.00 12.00 16.00) + 22.00 น. · AES-256 · ทดสอบกู้คืนทุกวันอาทิตย์ · สำรองก่อนกู้เสมอ

- [ ] **(?)** คลังแบบประเมิน: แก้แล้วเป็นเวอร์ชันใหม่ ผลเดิมใช้เกณฑ์ ณ วันประเมิน
- [ ] **(?)** อัตราค่าตอบแทน: ตั้งปีละครั้ง ใช้อัตรา ณ ปีงบของวันสอน · จำนวนวิทยากรที่เบิกได้เป็นค่าตัวอย่าง ให้การเงินตรวจ

- [ ] **(?)** รายงานสัปดาห์: ร่างศุกร์ 15.00 น. → ตรวจแก้ → อนุมัติ → พิมพ์
