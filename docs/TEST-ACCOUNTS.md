# บัญชีทดสอบ (ข้อมูลปลอมจาก `npm run seed` เท่านั้น)

> ⚠️ ใช้ได้เฉพาะ **เครื่องพัฒนา/ฐานข้อมูลปลอม** ที่สร้างด้วย `npm run seed` — ไม่ใช่รหัสของระบบใช้จริง
> เครื่องที่ทำงานตั้งรหัสหน่วยงานและรหัสผ่านใหม่ทั้งหมดตอนติดตั้ง (`install.ps1`) และห้ามนำรหัสในไฟล์นี้ไปใช้
> รัน `npm run seed` ใหม่เมื่อไร บัญชีและรหัสจะกลับเป็นค่าในไฟล์นี้ ("เครื่องที่จำไว้" ถูกล้าง ต้องใส่รหัสหน่วยงานใหม่)

## วิธีเข้าระบบ
1. เปิด `npm run dev` ในหน้าต่าง Terminal ของคุณเอง แล้วเปิด http://localhost:3000 (ให้หน้าต่างนั้นเปิดค้างไว้ตลอดที่ทดสอบ)
2. **ขั้นที่ 1 รหัสหน่วยงาน:** `demo-rehab-2569` (ตัวพิมพ์เล็กทั้งหมด มีขีดกลาง) — เครื่องจะจำไว้ 30 วัน
3. **ขั้นที่ 2 เลือกชื่อ** จากรายชื่อ แล้วใส่รหัสผ่าน:
   - **หัวหน้า/รอง (ผู้ดูแลระบบ):** `rehab-admin-2569` — ผู้ดูแลต้องใช้รหัสผ่านอย่างน้อย 12 ตัว (สเปก 2.1)
   - **บัญชีอื่นทั้งหมด:** `rehab-2569`
4. ไม่มี OTP — ผู้ดูแลเข้าระบบด้วยรหัสผ่านอย่างเดียว (สเปก 2.1: ค่าเริ่มต้นปิด OTP)

## ความปลอดภัยของผู้ดูแลระบบ (ทดสอบได้)
- **ไม่ใช้ OTP เป็นค่าเริ่มต้น** — ชดเชยด้วยรหัสผ่าน ≥ 12 ตัว + การกระทำสำคัญยืนยัน 2 คน + แจ้งเตือนเข้าระบบนอกเวลา
- **รหัสผ่านสั้นกว่า 12 ตัว:** ถ้าผู้ดูแลเข้าด้วยรหัสที่สั้นกว่า 12 ตัว (เช่น หลังได้รับสิทธิ์ผู้ดูแล) ระบบบังคับให้ตั้งรหัสใหม่ทันที
- **แจ้งเตือนนอกเวลาราชการ:** ผู้ดูแลคนหนึ่งเข้าระบบนอกเวลา (ค่าเริ่มต้น 07:00–18:00 จันทร์–ศุกร์ ไม่รวมวันหยุด) → อีกคนเห็นแจ้งเตือนที่กระดิ่ง
  ทดสอบ: ตั้งเวลาราชการที่ ตั้งค่า → ตั้งค่าระบบ → "ความปลอดภัยผู้ดูแลระบบ" ให้แคบลง → เข้าด้วยวิภาวรรณ → สลับไปธนพลแล้วดูกระดิ่ง
- **ถ้าเปิด OTP ในตั้งค่า (ไม่แนะนำในเรือนจำ):** ผู้ดูแลจะถูกพาไปตั้งค่า OTP — บนเครื่องพัฒนาใช้ `npm run dev:otp -- วิภาวรรณ` ดูรหัส 6 หลักแทนแอปมือถือ (ใช้ได้เฉพาะฐานข้อมูลปลอม)
## ถ้าเข้าระบบไม่ได้
| อาการ | ทำอย่างไร |
|---|---|
| หน้าเว็บไม่ขึ้น / ค้าง | ตรวจว่า `npm run dev` ยังทำงานอยู่ (ระหว่างที่ผู้พัฒนารัน `npm run seed` ต้องปิดเซิร์ฟเวอร์ชั่วคราว) |
| "รหัสหน่วยงานไม่ถูกต้อง" | พิมพ์ `demo-rehab-2569` ให้ตรงทุกตัว (ระวังภาษาไทย/Caps Lock) · ถ้าเพิ่งรัน seed ใหม่ รหัสยังเป็นค่าเดิม |
| "ใส่รหัสหน่วยงานผิดหลายครั้งเกินไป" | ผิด 10 ครั้งใน 15 นาที → รอตามเวลาที่แจ้ง หรือปิด-เปิด `npm run dev` ใหม่ (ตัวนับอยู่ในหน่วยความจำ) |
| "รหัสผ่านไม่ถูกต้อง" ตอนเข้าเป็นหัวหน้า/รอง | ผู้ดูแลใช้ `rehab-admin-2569` (ไม่ใช่ `rehab-2569`) |
| "บัญชีถูกล็อก" | ใส่รหัสผ่านผิด 5 ครั้ง → รอ 15 นาที หรือรัน `npm run seed` ใหม่ หรือให้หัวหน้ารีเซ็ตรหัส |
| กลับไปหน้ารหัสหน่วยงานทุกครั้ง | เบราว์เซอร์ลบคุกกี้ หรือมีการรัน seed ใหม่ (ล้างเครื่องที่จำไว้) — ใส่รหัสหน่วยงานใหม่ |
