# บัญชีทดสอบ (ข้อมูลปลอมจาก `npm run seed` เท่านั้น)

> ⚠️ ใช้ได้เฉพาะ **เครื่องพัฒนา/ฐานข้อมูลปลอม** ที่สร้างด้วย `npm run seed` — ไม่ใช่รหัสของระบบใช้จริง
> เครื่องที่ทำงานตั้งรหัสหน่วยงานและรหัสผ่านใหม่ทั้งหมดตอนติดตั้ง (`install.ps1`) และห้ามนำรหัสในไฟล์นี้ไปใช้
> รัน `npm run seed` ใหม่เมื่อไร บัญชีและรหัสจะกลับเป็นค่าในไฟล์นี้ (การตั้ง OTP และ "เครื่องที่จำไว้" ถูกล้าง)

## วิธีเข้าระบบ
1. เปิด `npm run dev` ในหน้าต่าง Terminal ของคุณเอง แล้วเปิด http://localhost:3000 (ให้หน้าต่างนั้นเปิดค้างไว้ตลอดที่ทดสอบ)
2. **ขั้นที่ 1 รหัสหน่วยงาน:** `demo-rehab-2569` (ตัวพิมพ์เล็กทั้งหมด มีขีดกลาง) — เครื่องจะจำไว้ 30 วัน
3. **ขั้นที่ 2 เลือกชื่อ** จากรายชื่อ แล้วใส่รหัสผ่าน `rehab-2569` (เหมือนกันทุกบัญชี)

|---|---|---|---|
| หัวหน้า | นางวิภาวรรณ ฟื้นฟูใจ | ผู้ดูแล + เจ้าหน้าที่หลัก + สถานพยาบาล | ต้องตั้ง OTP ครั้งแรก (ดูด้านล่าง) |

| พยาบาล (กลุ่ม A) | นางสาวศิริลักษณ์ ใจงาม · นางจิราพร ดูแลดี | เจ้าหน้าที่หลัก + สถานพยาบาล | ไม่ต้องใช้ OTP — **แนะนำใช้บัญชีนี้ทดสอบงานทั่วไป** |
| นักจิตวิทยา (กลุ่ม A) | นายกฤตภาส เข้าใจ · นางสาวปวีณา รับฟัง | เจ้าหน้าที่หลัก + สุขภาพจิต | |

| กลุ่ม B: นักสังคมสงเคราะห์ | นางสาวอรอุมา ช่วยเหลือ | ผู้ช่วย | ได้รับมอบหมายญาติ/ติดตาม/บสต. เฉพาะรุ่น 12 วัน 1/2570 → เมนู "งานที่ได้รับมอบหมาย" |

## OTP ของหัวหน้า/รอง (ผู้ดูแลระบบ)
ผู้ดูแลต้องยืนยัน OTP ทุกครั้งที่เข้าระบบ (สเปก 2.2A) — บนเครื่องพัฒนาไม่ต้องใช้แอปมือถือ:
1. เข้าระบบด้วยรหัสผ่านตามปกติ → ระบบพาไปหน้า "ตั้งค่า OTP" → กดปุ่ม "แสดง QR สำหรับสแกน"
2. เปิด Terminal อีกหน้าต่าง รัน `npm run dev:otp -- วิภาวรรณ` (หรือ `ธนพล`) → ได้รหัส 6 หลัก
3. ใส่รหัสในหน้าเว็บภายใน 30 วินาที — ครั้งต่อไปที่เข้าระบบ รันคำสั่งเดิมเพื่อดูรหัสใหม่

สคริปต์นี้ทำงานเฉพาะฐานข้อมูลที่ติดป้าย "ข้อมูลตัวอย่าง" (สร้างจาก seed) — ใช้กับฐานข้อมูลจริงไม่ได้

## ถ้าเข้าระบบไม่ได้
| อาการ | ทำอย่างไร |
|---|---|
| หน้าเว็บไม่ขึ้น / ค้าง | ตรวจว่า `npm run dev` ยังทำงานอยู่ (ระหว่างที่ผู้พัฒนารัน `npm run seed` ต้องปิดเซิร์ฟเวอร์ชั่วคราว) |
| "รหัสหน่วยงานไม่ถูกต้อง" | พิมพ์ `demo-rehab-2569` ให้ตรงทุกตัว (ระวังภาษาไทย/Caps Lock) · ถ้าเพิ่งรัน seed ใหม่ รหัสยังเป็นค่าเดิม |
| "ใส่รหัสหน่วยงานผิดหลายครั้งเกินไป" | ผิด 10 ครั้งใน 15 นาที → รอตามเวลาที่แจ้ง หรือปิด-เปิด `npm run dev` ใหม่ (ตัวนับอยู่ในหน่วยความจำ) |
| "บัญชีถูกล็อก" | ใส่รหัสผ่านผิด 5 ครั้ง → รอ 15 นาที หรือรัน `npm run seed` ใหม่ หรือให้หัวหน้ารีเซ็ตรหัส |
| กลับไปหน้ารหัสหน่วยงานทุกครั้ง | เบราว์เซอร์ลบคุกกี้ หรือมีการรัน seed ใหม่ (ล้างเครื่องที่จำไว้) — ใส่รหัสหน่วยงานใหม่ |
