# แบบฟอร์มต้นฉบับ (ภาพจากเจ้าของ — 5 ต.ค. 2569)

ภาพใน `source/` คือหน้ากระดาษแบบประเมินจริงที่หน่วยงานใช้ (จากคู่มือการฟื้นฟูฯ รูปแบบชุมชนบำบัด FAST model และคู่มือของกรมราชทัณฑ์)
ใช้เป็น "ต้นฉบับอ้างอิง" ตอนใส่ข้อความข้อคำถามในโปรแกรม — ไม่มีข้อมูลผู้ต้องขัง

## จุดที่แบบฟอร์มจริงไม่ตรงกับสเปก (ต้องให้เจ้าของเลือกก่อนทำขั้นที่ใช้)
1. **Rosenberg** — ไม่ได้ขัดกัน: เป็น **คนละฉบับ** (สเปก 16B · เจ้าของยืนยัน 10 ต.ค. 2569)
   ฉบับ 3 วัน (`ROSE3`): 10–20 ต่ำ / 21–30 ปานกลาง / 31–40 สูง · กลับคะแนน 2,5,6,8,9 (ข้อ 8 เชิงลบ)
   ฉบับชุมชนบำบัด (`ROSE`, ภาพ 10–11): 6 ระดับ 35–40 สูงมาก / 30–34 สูง / 25–29 ปานกลาง / 20–24 ค่อนข้างต่ำ / 15–19 ต่ำ / 10–14 ต่ำมาก (พร้อมแนวทางจัดการ) · กลับคะแนน 2,5,6,9 (ข้อ 8 เชิงบวก)
2. **แบบประเมินพฤติกรรม 27 ข้อ** — แบบฟอร์มเขียน 64–100 ปานกลาง / 100–135 ดี (100 ซ้อน) → ใช้ 64–99 ตามสเปกแล้ว
3. **WHOQOL-26** — แบบฟอร์มมีเกณฑ์รายองค์ประกอบ 4 ด้าน (กาย/จิต/สัมพันธภาพ/สิ่งแวดล้อม) ข้อ 1 และ 26 ไม่อยู่ในองค์ประกอบใด · ข้อกลับคะแนน 2, 9, 11

## การพิมพ์แบบฟอร์มการเงิน (สเปก 22)
- สร้างเป็น PDF ด้วย pdf-lib วางข้อความตามพิกัด มม. — พิกัดอยู่ที่ `src/lib/pdf/layouts/ktb.json` และ `voucher.json` (แก้ได้โดยไม่ต้องแก้โค้ด)
- แบบ KTB: พื้นหลัง = `source/22-ktb-transfer-form.pdf` (พิกัดวัดจากไฟล์นี้ด้วย pdfjs)
- ใบสำคัญรับเงิน: ยังไม่มีไฟล์ต้นฉบับ → วาดแบบฟอร์มเอง · ถ้าได้ไฟล์ .doc/.pdf ให้วางที่ `source/` แล้ววัดพิกัดใหม่และตั้ง `background` ใน voucher.json
- เครื่องพิมพ์เยื้อง → ตั้งค่า → ปรับตำแหน่งการพิมพ์ (พิมพ์ใบทดสอบ วัดเครื่องหมาย + ให้ห่างขอบ 20 มม.)
- ผู้พัฒนาตรวจด้วยตา: `npx tsx --conditions=react-server scripts/dev-pdf-sample.ts` → `public/dev-preview/sample.pdf` (ไม่เข้า Git)
## ต้นแบบบันทึกข้อความ (สเปก 18.3A)
- `memo-template.doc` — ต้นแบบจริงที่เจ้าของส่งมา (ห้ามแก้) · `assets/docs/memo-template.docx` = ไฟล์เดียวกันที่ Word แปลงเป็น .docx ใช้เป็นฐานสร้างไฟล์ Word ของระบบ
- ถ้าเปลี่ยนต้นแบบ: เปิด .doc ด้วย Word → บันทึกเป็น .docx ทับ `assets/docs/memo-template.docx` และบันทึกเป็น PDF ไว้ที่ `docs/screenshots/memo/template.pdf` → รัน `npx tsx scripts/memo-overlay.ts` ตรวจว่าคลาดไม่เกิน 2 มม.
