# แบบฟอร์มต้นฉบับ (ภาพจากเจ้าของ — 5 ต.ค. 2569)

ภาพใน `source/` คือหน้ากระดาษแบบประเมินจริงที่หน่วยงานใช้ (จากคู่มือการฟื้นฟูฯ รูปแบบชุมชนบำบัด FAST model และคู่มือของกรมราชทัณฑ์)
ใช้เป็น "ต้นฉบับอ้างอิง" ตอนใส่ข้อความข้อคำถามในโปรแกรม — ไม่มีข้อมูลผู้ต้องขัง

> PMHQ-Thai สงวนลิขสิทธิ์โดยกรมราชทัณฑ์ — ใช้ภายในหน่วยงานตามที่ได้รับ ไม่เผยแพร่ภายนอก
> SCL-90-R และ WHOQOL เป็นเครื่องมือที่มีเจ้าของลิขสิทธิ์ — ก่อนใช้ในขั้น 5 ควรยืนยันว่าหน่วยงานได้รับอนุญาตใช้แล้ว

| ไฟล์ | แบบ | ใช้ในโปรแกรม |
|---|---|---|
| 01–03 | คุณภาพชีวิตผู้ใช้สารเสพติด WHOQOL-26 (การให้คะแนน + 26 ข้อ) | ขั้น 5 (ชุมชนบำบัด) — ยังไม่ใส่ |
| 04–07 | SCL-90-R 90 ข้อ | ขั้น 5 (ระยะแรกรับ) — ยังไม่ใส่ (ภาพไม่มีวิธีคิดคะแนน 9 มิติ ต้องขอเพิ่ม) |

| 10–11 | Rosenberg Self-Esteem 10 ข้อ + เกณฑ์ | ขั้น 4–5 — ยังไม่ใส่ (เกณฑ์ไม่ตรงสเปก ดูด้านล่าง) |
| 12 | สภาวะร่างกาย/จิตใจในการเข้ารับการบำบัด | ✅ `COND` (ขั้น 2) |

| 17 | หน้าสรุปผลรายบุคคล (ก่อน/หลัง) | ขั้น 5 (สมุดสมาชิก ส่วนที่ 2.9) |

## จุดที่แบบฟอร์มจริงไม่ตรงกับสเปก (ต้องให้เจ้าของเลือกก่อนทำขั้นที่ใช้)
1. **Rosenberg** — สเปกหัวข้อ 17: 10–20 ต่ำ / 21–30 กลาง / 31–40 สูง
   แบบฟอร์มจริง (ภาพ 11): 6 ระดับ 35–40 สูงมาก / 30–34 สูง / 25–29 ปานกลาง / 20–24 ค่อนข้างต่ำ / 15–19 ต่ำ / 10–14 ต่ำมาก (พร้อมแนวทางจัดการ)
2. **แบบประเมินพฤติกรรม 27 ข้อ** — แบบฟอร์มเขียน 64–100 ปานกลาง / 100–135 ดี (100 ซ้อน) → ใช้ 64–99 ตามสเปกแล้ว
3. **WHOQOL-26** — แบบฟอร์มมีเกณฑ์รายองค์ประกอบ 4 ด้าน (กาย/จิต/สัมพันธภาพ/สิ่งแวดล้อม) ข้อ 1 และ 26 ไม่อยู่ในองค์ประกอบใด · ข้อกลับคะแนน 2, 9, 11
