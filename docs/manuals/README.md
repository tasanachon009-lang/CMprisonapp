## สิ่งที่นำไปใช้แล้วจากคู่มือ 12 วัน
- ตารางการปฏิบัติประจำวัน (ข้อ 11 หน้า 7 ของเล่ม) → แม่แบบตาราง 12 วัน (`B12_TEMPLATE` ใน `src/lib/reference-data.ts`)
- จุดประสงค์การเรียนรู้ของแต่ละแผน → ชิป "สิ่งที่ได้" ของหัวข้อ (`B12_CHIPS`) — สรุปย่อ รอผู้ดูแลตรวจในคลังหัวข้อ
- โครงสร้าง 4 กลุ่มวิชา (ข้อ 10) → หมวดของหัวข้อ

## ยังไม่ได้นำไปใช้
- เกณฑ์รับเข้า/ลักษณะต้องห้าม (ข้อ 5) · ตัวชี้วัด (ข้อ 4) · ใบงาน/ใบความรู้ · แบบประเมินท้ายเล่ม — ยังไม่ได้เทียบกับที่ระบบมี
