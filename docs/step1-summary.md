# สรุปขั้นที่ 1: โครงพื้นฐานและหลักสูตร 12 วัน

## ทำอะไรไปแล้ว
- โครงโปรเจกต์ Next.js + TypeScript + Tailwind + SQLite (Drizzle, WAL, busy_timeout 5000), Git และ .gitignore ที่กันไฟล์ข้อมูล/สำรอง/.env/Excel
- ฐานข้อมูลตามหัวข้อ 5 (บุคคล → การต้องโทษ → ลงทะเบียน → รุ่น → หลักสูตร) พร้อม unique index กันซ้ำที่ระดับฐานข้อมูล และ audit log ที่แก้/ลบไม่ได้ (trigger)
- เข้าระบบ 2 ชั้น (รหัสหน่วยงานจำ 30 วัน + การ์ดชื่อ + รหัสผ่าน Argon2), บังคับเปลี่ยนรหัสครั้งแรก, ผิด 5 ครั้งล็อก 15 นาที + แจ้งผู้ดูแล, แจ้งเมื่อเข้านอกเวลาราชการ, สลับผู้ใช้
- ล็อกหน้าจอด่วน (ปุ่มแม่กุญแจ / Ctrl+L / Esc 2 ครั้ง / ไม่ใช้ 15 นาที เตือนก่อน 1 นาที) งานที่พิมพ์ค้างไม่หาย
- บทบาท 8 แบบ + สิทธิ์รายคน/รายรุ่น/ช่วงวันที่ ตรวจที่เซิร์ฟเวอร์ทุกหน้าและทุก action, เมนูที่ไม่มีสิทธิ์ถูกซ่อน, ผู้ดูแลไม่เกิน 2 คน
- ยืนยัน 2 คน (กู้คืน / ให้-ถอนสิทธิ์ผู้ดูแล) + รหัสฉุกเฉินที่ใช้แล้วต้องสร้างใหม่
- สำรองข้อมูล: SQLite online backup → gzip → AES-256-GCM, checksum ทุกสำเนา, 3 ชุด, เก็บตามนโยบาย 30/12/12/รายปี, ทำย้อนหลังเมื่อเปิดเครื่อง, ทดสอบกู้คืนอัตโนมัติรายสัปดาห์, ตรวจดิสก์ภายนอกทุก 5 นาที, แถบแดง
- หลักสูตร/รุ่น 12 วัน: สร้างรุ่นคำนวณวันสิ้นสุดข้ามวันหยุด + สร้างตารางจากแม่แบบ, หน้ารุ่นมีแท็บ ภาพรวม/รายชื่อ/เช็คชื่อ/ตาราง
- ลงทะเบียนแบบ 6 ขั้น (กันซ้ำ 3 กฎ, อาจเป็นคนเดียวกัน, ปลดล็อกโดยผู้ดูแล, PDPA consent, บันทึกร่างทุก 30 วินาที)
- นำเข้า Excel พร้อมแม่แบบ ตรวจทุกแถว 5 ประเภท นำเข้าเฉพาะที่ผ่าน ดาวน์โหลดแถวไม่ผ่านพร้อมเหตุผล รองรับรุ่นเก่าพร้อมสถานะ
- บันทึกออกจากเรือนจำทีละหลายคน → ออกก่อนกำหนด + ตัดจากเช็คชื่อตั้งแต่วันนั้น + สรุปสิ่งที่ระบบทำ, ยกเลิกแล้วย้อนให้ครบ
- เช็คชื่อ (ค่าเริ่มต้น "มา", เหตุราชทัณฑ์ไม่หัก %, รูปย่อ 32px + กดค้างดูรูปใหญ่, ป้ายชื่อซ้ำ, กันบันทึกทับ, เลิกทำ 10 วินาที) + โหมดกรอกเร็ว (คีย์บอร์ดล้วน วางจาก Excel ได้)
- หน้าบุคคล: การต้องโทษปัจจุบันเป็นหลัก รอบเก่าพับเก็บพร้อมป้ายแดง, เลขบัตรปิดบัง กดดูเต็มบันทึก audit, อัปโหลดรูปย่ออัตโนมัติ 800/200 px
- หน้าแรกตามบทบาท, ใบเซ็นชื่อ/ใบเช็คชื่อ/แบบยินยอม/ใบนับยอดผู้คุม พร้อมท้ายกระดาษ "พิมพ์โดย"
- ติดตั้งใช้จริง: server HTTPS, Windows Service, install.ps1, update.ps1 (ย้อนกลับอัตโนมัติ), ชุดออฟไลน์, README ภาษาไทย

## รายการงานทดสอบสำหรับเจ้าหน้าที่ (ใช้ข้อมูลปลอม)
**หัวหน้า/รอง (ผู้ดูแล):** สร้างรุ่นใหม่ · ลงทะเบียนคนที่มีอยู่แล้ว (ต้องถูกบล็อก) แล้วปลดล็อกพร้อมเหตุผล · เพิ่มผู้ใช้/รีเซ็ตรหัส/ระงับบัญชี · มอบหมายผู้ช่วยรายรุ่น · สำรองทันที + ทดสอบกู้คืน · ขอกู้คืนแล้วให้อีกคนยืนยัน · ดูประวัติการใช้งาน · เพิ่มวันหยุด
**พยาบาล/นักจิตวิทยา:** ลงทะเบียนครบ 6 ขั้น (มี/ไม่มีเลขบัตร) · เช็คชื่อคาบวันนี้ (ใส่ ขาด/ลา/เหตุราชทัณฑ์) แล้วกดเลิกทำ · โหมดกรอกเร็ว · บันทึกออกจากเรือนจำ 2 คน แล้วยกเลิก 1 คน · เพิ่มรูปถ่าย · พิมพ์ใบเซ็นชื่อ · กด Ctrl+L ระหว่างพิมพ์ฟอร์มแล้วปลดล็อก
**ผู้ช่วย (นักฝึกอบรมวิชาชีพ/นักสังคมสงเคราะห์):** เห็นเฉพาะ "คาบของฉันวันนี้" · เช็คชื่อคาบตัวเองได้ · ลองเปิด URL คาบอื่น/หน้าบุคคล ต้องถูกปฏิเสธ
**การเงิน:** เข้าได้เฉพาะหลักสูตร/ตาราง (งานการเงินจริงอยู่ขั้นที่ 3) · เปิดหน้าบุคคลต้องถูกปฏิเสธ
**ผู้บริหาร:** เห็นภาพรวมตัวเลข ไม่มีปุ่มแก้ไข · ดูรายชื่อ/บุคคลได้ แต่ลงทะเบียน/นำเข้าไม่ได้
**ผู้ควบคุม (ถ้าเปิดบัญชี):** เห็นเฉพาะใบรายชื่อนับยอด + รูป
