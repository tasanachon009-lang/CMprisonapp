# สรุปขั้นที่ 3: ตาราง วิทยากร ค่าตอบแทน งบประมาณ LINE

## ทำอะไรไปแล้ว
**ข้อมูลตั้งต้น (สเปก 11.1–11.3, 11.5B)**
- อัตราค่าตอบแทน (บาท/ชม. เพดานต่อวัน ใช้ตั้งแต่ปีงบ) — ⚠️ ยังเป็น **อัตราตัวอย่าง** ติดป้ายไว้ รอการเงินแก้เป็นอัตราจริง
- ทะเบียนวิทยากรภายใน/ภายนอก: ที่อยู่แยกช่อง (เลือกตำบลแล้วเติมอำเภอ/จังหวัด/รหัสไปรษณีย์ให้) บัญชี KTB สถานะ "พร้อมเบิก/ข้อมูลไม่ครบ" · เลขบัตร/บัญชีเห็นเต็มเฉพาะการเงิน/ผู้ดูแล
- คลังหัวข้อทั้ง 3 หลักสูตร: รายบุคคล/ทั้งทีม เบิกได้หรือไม่ อัตรา วิธีแบ่ง (คนละเต็ม/หารเท่ากัน/สัดส่วน) ผู้รับผิดชอบประจำ · ชิป "สิ่งที่ได้" (ชุดร่าง)

**ตารางของรุ่น (สเปก 11.4, 22B)**
- คัดลอกตารางจากรุ่นก่อน · ปฏิทินรายสัปดาห์ลากย้ายคาบ · เปลี่ยนวิทยากรเป็นช่วง · ตรวจชนเวลา/สถานที่ซ้อน/เกินจำนวนที่เบิกได้
- ปฏิทินรวมทุกหลักสูตร + รายการความทับซ้อนก่อนพิมพ์ตารางแจก
- ผู้รับผิดชอบประจำวันรายรุ่น (หมุนเวียนกลุ่ม A แก้ได้) · ยอดค่าตอบแทนรายคนในหน้าแก้คาบ · ผู้ดูแลแก้วิธีแบ่งเฉพาะคาบ (+หมายเหตุ)
- สถานะเชิญวิทยากรภายนอก + เตือน 14 วัน + ปุ่มคัดลอกข้อความแจ้งกำหนดสอน

**คาบของฉัน / บันทึกผลหลังสอน (สเปก 11.5, 22B)**
- หน้าเดียว: เช็คชื่อ + ผลกิจกรรม 3 ขั้นแบบกดเลือก (ปุ่มใหญ่ หน้ายิ้ม ชิป) + สอนจริงรายคน → "บันทึกและปิดคาบ"
- บันทึกแทนวิทยากรภายนอก (เก็บผู้สอน/ผู้บันทึกแยก) · คัดลอกจากใบบันทึกของวิทยากร · ชิป "มีเหตุการณ์ต้องแจ้งเวร" เปิดจดหมายเวรพร้อมเติมรุ่น/คาบ
- ป้าย "ควรจัดสอนชดเชย" + สร้างคาบชดเชย (เฉพาะคนที่ติดเหตุราชทัณฑ์) · หน้าแรกป้ายแดงคาบที่ยังไม่บันทึกผล
- ใบพิมพ์ "บันทึกผลการจัดกิจกรรม" (ต่อคาบ/ต่อวัน) และ "บันทึกหลังสอน" สำหรับวิทยากรภายนอก

**ค่าตอบแทน (สเปก 11.5–11.6, 22B)**
- คิดจากสอนจริงของคาบที่ปิดแล้ว · คาบเดียวภายใน+ภายนอกคิดคนละอัตรา · เพดานต่อวัน · **ไม่มีหักภาษี ณ ที่จ่าย** (เจ้าของยืนยัน)
- รอบเบิก (รุ่น + ช่วงวันที่) → หัวหน้า/รองอนุมัติ = ยอดคงที่ + **ล็อกคาบ** · ไม่เบิกซ้ำ · ปลดล็อกต้องมีเหตุผล · อนุมัติยอดของตัวเองไม่ได้
- มอบอำนาจอนุมัติชั่วคราว (ค่าตอบแทน/งบ/ตาราง) หมดเวลาคืนสิทธิ์เอง · audit "อนุมัติแทน"
- สรุปรายคน/รุ่น/เดือน/ปีงบ ที่มาของยอดทุกบรรทัด สัดส่วนภายใน:ภายนอก · ภาระงานชั่วโมงสอน (รวมคาบที่เบิกไม่ได้)

**เอกสารการเงิน (สเปก 11.5C/D, 22)**
- PDF ด้วย pdf-lib ฝังฟอนต์ TH Sarabun New · จัดสระ/วรรณยุกต์ไทยด้วยรูปอักษรสำรอง (กฎเดียวกับ HarfBuzz)
- **แบบ KTB**: ใช้ไฟล์ต้นฉบับเป็นพื้นหลัง พิกัดวัดจากไฟล์ (JSON แก้ได้) · **ใบสำคัญรับเงิน**: วาดตามพิกัด (ยังไม่มีไฟล์ต้นฉบับ) เพิ่มเลขบัตร/เบอร์โทรตามสเปก · ยอดยกไป/ยกมา · จำนวนเงินตัวอักษร (แบบ BAHTTEXT)
- ชุดเอกสารส่งการเงิน: สรุปใหญ่ + ใบสำคัญฯ/KTB เป็นคู่ + รายละเอียด · ตรวจยอด 4 จุดก่อนพิมพ์ · วันที่ "ไม่ใส่" ได้ · สถานะพิมพ์แล้ว/เซ็นรับ/ต้องพิมพ์ใหม่ · Excel
- หน้า "ปรับตำแหน่งการพิมพ์" ±15 มม. + ใบทดสอบเครื่องหมาย 20 มม.

**งบประมาณ (สเปก 13)**
- จัดสรรต่อปีงบ (แหล่งเงิน เลขหนังสือ ถัวได้/ห้ามถัว) → งบของรุ่นตามสูตร · แม่แบบหลักสูตร · คัดลอกจากรุ่นก่อน
- เงินเป็นสตางค์ + CHECK ฐานข้อมูล · **รวมทุกรุ่นห้ามเกินจัดสรร (โปรแกรม + trigger ฐานข้อมูล)**
- ค่าวิทยากรตัดงบเฉพาะรอบที่อนุมัติแล้ว (ปลดล็อก = คืนงบ) · ยอดหน้างบ = สรุปใหญ่ = ผลรวมใบสำคัญรับเงิน
- เกินหมวด: ถัวได้ = เหลือง / ห้ามถัว = แดง ต้องหัวหน้า/รองยืนยัน · คืนเงินเหลือ · รายงานแยกหมวด งบต่อหัว % ประหยัด

**LINE และรายงานประจำสัปดาห์ (สเปก 12, 18.2)**
- Broadcast ตารางวันทำการถัดไป (16.00 ตั้งได้) · ศุกร์ส่งตารางสัปดาห์หน้า · แก้ตารางหลังส่ง → แจ้งเปลี่ยนแปลงอัตโนมัติ
- **โหมดทดลอง** เมื่อไม่มี token หรือเป็นฐานข้อมูลปลอม (ไม่ส่งจริง) · ตรวจซ้ำกันข้อมูลผู้ต้องขังก่อนส่ง · ส่งไม่สำเร็จแจ้งผู้ดูแล + ปุ่มคัดลอกข้อความ · โควตาเดือนนี้
- รายงานประจำสัปดาห์ 6 ส่วน: ร่างอัตโนมัติศุกร์ 15.00 → แก้ข้อความ → อนุมัติ → พิมพ์บันทึกข้อความ (PDF/Word) · ส่ง "สรุปตัวเลข" ทาง LINE ได้ (ตั้งค่า)
- พิมพ์ตารางสอนรายบุคคลรายสัปดาห์จากหน้าแรก
- README หัวข้อ 11: ขั้นตอนสร้าง LINE OA และขอ Channel Access Token ทีละขั้น

## ผลตรวจความปลอดภัย
- ตรวจสิทธิ์ที่เซิร์ฟเวอร์ทุกหน้า/ทุก action (รวมค่าตอบแทน เอกสารการเงิน งบ มอบอำนาจ LINE รายงานสัปดาห์) — 201/201
- เงิน: อนุมัติยอดตัวเองไม่ได้ · ปลดล็อกเฉพาะหัวหน้า/รอง+เหตุผล · ฐานข้อมูลกันงบเกินจัดสรรและบังคับสตางค์จำนวนเต็ม
- ข้อมูลอ่อนไหวของวิทยากร (เลขบัตร/บัญชี) เห็นเต็มเฉพาะการเงิน/ผู้ดูแล · Excel ค่าตอบแทนไม่มีเลขบัตร/บัญชี
- เชื่อมต่อออกเฉพาะ `api.line.me` · ข้อความ LINE/รายงานสัปดาห์ไม่มีข้อมูลผู้ต้องขัง (ทดสอบแล้ว) · token อยู่ใน `.env` เท่านั้น ไม่แสดงบนหน้าจอ

## ยกไปขั้นถัดไป / ต้องการจากเจ้าของ
- **อัตราค่าตอบแทนจริง** และหัวข้อที่เบิกได้ (ตอนนี้ใช้อัตราตัวอย่าง)
- **ไฟล์ต้นฉบับใบสำคัญรับเงิน** (.doc/.pdf) เพื่อใช้เป็นพื้นหลังแบบเดียวกับแบบ KTB
- **ไฟล์คู่มือทั้ง 3 หลักสูตร** เพื่อปรับชิป "สิ่งที่ได้" ให้ตรงจุดประสงค์การเรียนรู้
- แม่แบบงบ 12 วัน (ตอนนี้เป็นค่าสมมติ) · หน่วยงานเบิกจ่ายจาก สปสช. หรือไม่ (สเปก 24)
- รายงานประจำเดือน + ขั้นตอนเสนอผู้บริหาร (สเปก 18.2A) · ส่ง LINE แยกรายคน (เมื่อฝ่าย IT อนุญาต webhook)
- ขั้น 4: หลักสูตร 3 วัน + เอกสารราชการ (สเปก 17, 18.4)
