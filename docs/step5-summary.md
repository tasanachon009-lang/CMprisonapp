# สรุปขั้นที่ 5: ชุมชนบำบัด FAST Model 6 เดือน

งานกลุ่ม C1–C5 เสร็จเมื่อ 11 ต.ค. 2569 (สเปก 10, 13, 16, 16A, 16B) — ข้อมูลในเครื่องพัฒนาเป็นข้อมูลปลอมจาก `npm run seed` ทั้งหมด

**สถานะ: ใช้ทดสอบได้ครบทุกกลุ่ม แต่ยังไม่ถือว่าปิดขั้น** เพราะยังไม่ได้เทียบกับคู่มือ FAST และแบบฟอร์มจริงของกรมฯ (ดูหัวข้อ "ยังไม่ได้ทำ" และ "สิ่งที่รอจากเจ้าของ")

## ทำอะไรไปแล้ว

**C1 ตั้งค่าหลักสูตร (commit `5b4b3b9`)**
- เปิดใช้หลักสูตรชุมชนบำบัด 24 สัปดาห์ · 5 ระยะ คำนวณระยะตามสัปดาห์อัตโนมัติ · เลื่อนระยะต้องผ่านเงื่อนไขและผู้ดูแลระบบอนุมัติ · ย้อนระยะได้พร้อมเหตุผล
- เกณฑ์รับเข้า: อายุ 18–60 ปี ชั้นกลางขึ้นไป ตรวจอัตโนมัติ + ข้อยืนยัน
- แม่แบบตาราง 24 สัปดาห์ (ร่างจากสเปก) · วันหยุดราชการไม่มีคาบ สัปดาห์ไม่เลื่อน

**C2 สมุดบันทึกความก้าวหน้า (commit `ab5e61b`, `fe32d9e`)**
- สมุดของสมาชิก ส่วนที่ 1–4 · ตัวช่วยรายเดือน (การเข้าร่วม คะแนนพฤติกรรม ระยะ เครื่องมือ/วินัย) · เตือนเดือนที่ยังไม่ได้บันทึก · พิมพ์สมุดได้
- แบบประเมิน: 2Q→9Q→8Q ต่อกันอัตโนมัติ · Rosenberg ฉบับ FAST · WHOQOL-26 (คะแนนรวม + 4 ด้าน) · SCL-90-R อยู่ในคลังแต่ปิดใช้งาน
- คลังแบบประเมิน: วางข้อความข้อคำถามหลายข้อพร้อมกันได้ · เปิด/ปิดใช้งานแบบได้

**C3 โครงสร้างบ้าน (commit `e4dc360`)**
- ตำแหน่ง 6 ระดับ · ทีมงาน 3 ทีม · ผังบ้าน · กำหนดหลายคนพร้อมกัน · ประวัติเลื่อน/ลดตำแหน่งและหมุนทีม
- เตือนอัตราส่วนเจ้าหน้าที่ 1:15 / พี่เลี้ยง 1:10 และอยู่ทีมเดิมเกิน 2 เดือน · ประเมินทีมรายสัปดาห์

**C4 เครื่องมือบ้าน วินัย รางวัล (commit `2476342`)**
- เครื่องมือ 8 ชนิด แนะนำขั้นถัดไปเมื่อผิดเรื่องเดิมซ้ำ · Hair cut มีใบร้องขอ · Shot down / LE มีวันครบกำหนดและต้องบันทึกผลตอนปลด
- กฎ 5 ข้อใหญ่บันทึกแยก แจ้งผู้ดูแลระบบทันที · วินัยอื่นมีประเภท + ระดับ · รางวัล 3 ชนิด
- แปลงบันทึกพฤติกรรมด่วนเชิงลบเป็นบันทึกวินัย/เครื่องมือบ้านได้ · ออกจากเรือนจำแล้วเครื่องมือที่ค้างถูกยกเลิก

**C5 รายงานสิ้นสุดรุ่น (commit `7a82e8f`)**
- หน้าพิมพ์จากแท็บรายงาน/แท็บเอกสารของรุ่น 6 หัวข้อ: จำนวนสมาชิกชาย/หญิง (เข้า / ไม่จบ + สาเหตุ / จบอยู่ในเรือนจำ / จบปล่อยตัว / คงเหลือ) · ผู้กลับมาต้องโทษซ้ำ · ผลดำเนินงาน 5 ด้าน · บสต./รท.101 เป้า-จริง · งบประมาณ · ปัญหา ข้อเสนอแนะ
- ตัวเลขรวมเท่านั้น ไม่มีชื่อ · เตือนเมื่อตัวเลขสมาชิกไม่สอดคล้อง · บันทึกการพิมพ์

## รายการงานทดสอบตามบทบาท (ข้อมูลปลอม — รหัสอยู่ที่ `docs/TEST-ACCOUNTS.md`)

**หัวหน้า (วิภาวรรณ) / รองหัวหน้า (ธนพล)**
1. หลักสูตร → ชุมชนบำบัด → รุ่นที่ 1/2569 → แท็บชุมชนบำบัด: ดูระยะของสมาชิก · เลือกสมาชิกที่ถึงกำหนด → อนุมัติเลื่อนระยะ · ลองย้อนระยะ 1 คน (ต้องใส่เหตุผล)
2. ลงทะเบียนสมาชิกใหม่ 1 คน: ลองอายุ 17 ปี หรือชั้นต้องปรับปรุง (ต้องยืนยันรับเข้าไม่ได้)
3. ผังบ้าน: กำหนดตำแหน่งและทีมให้หลายคนพร้อมกัน · ดูคำเตือนอัตราส่วนและ "อยู่ทีมเดิมเกิน 2 เดือน"
4. เครื่องมือบ้าน: บันทึกการละเมิดกฎ 5 ข้อใหญ่ 1 รายการ → ต้องมีแจ้งเตือนในระบบ → บันทึกผลเพื่อปิดเรื่อง
5. แท็บรายงาน → รายงานสิ้นสุดรุ่น (ชุมชนบำบัด): ตรวจจำนวนสมาชิกกับรายชื่อจริง และต้องไม่มีชื่อในรายงาน
6. ตั้งค่า → รายการตัวเลือก: แก้ชื่อตำแหน่ง/ทีม/ประเภทความผิดวินัย · ตั้งค่า → คลังแบบประเมิน: วางข้อความ WHOQOL-26 หลายข้อพร้อมกัน

**เจ้าหน้าที่ฟื้นฟู**
1. เปิดสมาชิก 1 คน → สมุดของสมาชิก: กรอกส่วนที่ 1 · บันทึกรายเดือนส่วนที่ 3 (ดูตัวช่วยของเดือน) · เพิ่มความเห็นที่ปรึกษาส่วนที่ 4 · พิมพ์สมุด
2. บันทึกพฤติกรรมด่วนเชิงลบ → กด "แปลงเป็นบันทึกวินัย/เครื่องมือบ้าน" → บันทึกเครื่องมือ → ผิดเรื่องเดิมซ้ำ ต้องแนะนำขั้นถัดไป
3. บันทึก Shot down หรือ LE → เมื่อครบกำหนดต้องมีแถบเตือน → กดปลดพร้อมผลลัพธ์
4. ทีมงาน: ประเมินทีมรายสัปดาห์ · ลองกดเลื่อนระยะ (ต้องทำไม่ได้ — เสนอได้อย่างเดียว)
5. กรอกแบบประเมินด้วยโหมดกรอกเร็ว: ความก้าวหน้า 27 ข้อ รายเดือน และ WHOQOL-26

**พยาบาล / นักจิตวิทยา**
1. กรอก 2Q ให้ผลบวก → ระบบต้องเปิด 9Q ต่อ → คะแนนถึงเกณฑ์ต้องเปิด 8Q ต่อ
2. เปิดแท็บชุมชนบำบัด: ดูได้ แต่ต้องแก้ไขไม่ได้ · เปิดรายงานสิ้นสุดรุ่นได้

**กลุ่ม B (ผู้ช่วย) / การเงิน / ผู้คุม**
1. พิมพ์ URL ของแท็บชุมชนบำบัด ผังบ้าน เครื่องมือบ้าน สมุดของสมาชิก และรายงานสิ้นสุดรุ่นโดยตรง → ต้องถูกปฏิเสธทุกหน้า

**ผู้บริหาร**
1. แท็บชุมชนบำบัด ผังบ้าน เครื่องมือบ้าน: ต้องเห็นเฉพาะจำนวน ไม่มีชื่อหรือพฤติกรรมรายคน
2. เปิดรายงานสิ้นสุดรุ่นได้ · เปิดสมุดของสมาชิกและหน้าทีมงานไม่ได้

## ผลตรวจความปลอดภัย
- ตรวจสิทธิ์ที่เซิร์ฟเวอร์ทุกหน้าและทุก action ของขั้นนี้ (`tc.view` / `tc.edit` / `tc.approve` / `tc.summary`)
- ผู้บริหารเห็นเฉพาะสรุปไม่ระบุชื่อในทุกหน้าของชุมชนบำบัด · รายงานสิ้นสุดรุ่นไม่มีนามสกุล/เลขประจำตัว (ตรวจกับสมาชิกทุกคนของรุ่น)
- สมุดของสมาชิกและรายงานสิ้นสุดรุ่นบันทึกการพิมพ์ · เปิดกับหลักสูตรอื่นไม่ได้
- แจ้งเตือนกฎ 5 ข้อใหญ่ส่งในระบบเท่านั้น ไม่ส่ง LINE
- ไม่มีหน้าจอให้ผู้ต้องขังใช้เอง — แบบที่สมาชิกตอบเองใช้กระดาษแล้วเจ้าหน้าที่กรอก

## ยังไม่ได้ทำ
- แบบประเมินเพิ่มเติมของ FAST: ความรู้ Matrix (ผ่าน ≥ 70%) · ประเมินตนเอง 3 ข้อ · ความพึงพอใจ 6/30 ข้อ
- SCL-90-R: ยังคิดคะแนนรายด้านไม่ได้ (ปิดใช้งานไว้)
- ข้อความข้อคำถาม WHOQOL-26 / SCL-90-R ยังเป็น "ข้อที่ n ตามแบบกระดาษ" จนกว่าจะวางข้อความในคลังแบบประเมิน
- ข้อมูลฝึกวิชาชีพ/บ้านกึ่งวิถีรายคน (รายงานมีเพียงจำนวนครั้งและชั่วโมง)
- แจ้งเตือนอัตโนมัติรายวัน (เครื่องมือครบกำหนดปลด · ถึงกำหนดเลื่อนระยะ) — ตอนนี้เป็นแถบเตือนในหน้า
- ช่องพิมพ์ข้อความบรรยายในรายงานสิ้นสุดรุ่น (ตอนนี้เว้นบรรทัดให้เขียนด้วยมือ)
- ภาพหน้าจอชุดเต็มของหน้าใหม่ · คู่มือแยกบทบาท (`docs/HELP-TODO.md`)

## สิ่งที่รอจากเจ้าของ (เฉพาะขั้น 5 — รายการของขั้นก่อนอยู่ที่ `docs/step4-summary.md`)
1. **คู่มือ FAST Model ของกรมฯ (ไฟล์)** — ตรวจแม่แบบตาราง 24 สัปดาห์ เงื่อนไขเลื่อนระยะ และชื่อตำแหน่ง/ทีม
2. **แบบรายงานสิ้นสุดรุ่นของกรมฯ** — ตอนนี้โครงหน้าร่างจากสเปก
3. **ภาพสมุดบันทึกความก้าวหน้าของสมาชิก** (ถ้ามีฉบับจริง) — ตรวจหัวข้อส่วนที่ 1–4
4. **หน้า "วิธีคิดคะแนนรายด้าน" ของ SCL-90-R** — ใช้เปิดใช้งานแบบ
5. **แบบประเมินเพิ่มเติม**: ความรู้ Matrix · ประเมินตนเอง · ความพึงพอใจ
6. วางข้อความข้อคำถาม WHOQOL-26 (และ SCL-90-R) ในคลังแบบประเมินด้วยช่อง "วางข้อความหลายข้อพร้อมกัน"
7. ตรวจเรื่องที่ระบบเลือกไปก่อน: `docs/decisions.md` — ตาราง "รอฉันยืนยัน" ข้อ 12–22 และหัวข้อ C3 (ข้อ 23–26), C4 (ข้อ 27–32), C5 (ข้อ 33–38)
